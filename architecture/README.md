# architecture

## Purpose

This directory remains reserved for implementation-facing diagrams and support assets.
The current architecture documentation entry point is
[`docs/architecture/README.md`](../docs/architecture/README.md).

## What Belongs Here

- Derived architecture notes approved by Engineering Directives.
- Diagrams or implementation maps that reference the canonical documents.
- Architecture review artifacts that help engineers implement approved decisions.

## What Does Not Belong Here

- Replacements for `PRODUCT_CONSTITUTION.md` or files in `docs/`.
- Unapproved architecture decisions.
- Application code, API definitions, database schemas, or infrastructure configuration.

## Expected Future Directives

Future directives may add approved implementation maps or diagrams here when those
artifacts are clearer outside the canonical Markdown architecture set. Do not place
unapproved decisions or duplicate architecture documents here.
