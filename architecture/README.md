# architecture

## Purpose

This directory is reserved for implementation-facing architecture support material that complements the canonical specifications.

## What Belongs Here

- Derived architecture notes approved by Engineering Directives.
- Diagrams or implementation maps that reference the canonical documents.
- Architecture review artifacts that help engineers implement approved decisions.

## What Does Not Belong Here

- Replacements for `PRODUCT_CONSTITUTION.md` or files in `docs/`.
- Unapproved architecture decisions.
- Application code, API definitions, database schemas, or infrastructure configuration.

- ED-0003 Frontend Foundation may add frontend architecture support notes.
- ED-0005 Production Context Foundation may add production-context implementation maps.
