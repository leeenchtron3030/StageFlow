# examples

## Purpose

This directory is reserved for small examples that demonstrate approved patterns without becoming production code.

## What Belongs Here

- Minimal examples tied to future Engineering Directives.
- Sample payloads or usage snippets once APIs or adapters are approved.
- Documentation examples that help contributors understand repository conventions.

## What Does Not Belong Here

- Production application code.
- Prototype features that bypass the specification-first process.
- Real customer, event, media, or credential data.

## Expected Future Directives

- ED-0002 Backend Foundation may add backend examples.
- ED-0003 Frontend Foundation may add frontend examples.
- Future integration directives may add adapter examples.
