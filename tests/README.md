# tests

## Purpose

This directory is reserved for automated tests once implementation begins.

## What Belongs Here

- Unit tests.
- Integration tests.
- Contract tests.
- Test fixtures that reference mock data rather than real production data.

## What Does Not Belong Here

- Production application code.
- Manual QA notes.
- Real event data, recordings, transcripts, or customer information.
- Test runners or configuration files before tooling is approved.

## Expected Future Directives

- ED-0002 Backend Foundation may add backend tests.
- ED-0003 Frontend Foundation may add frontend tests.
- ED-0004 Development Tooling may add test runner configuration.
