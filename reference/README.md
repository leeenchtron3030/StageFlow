# reference

## Purpose

This directory is reserved for non-authoritative reference material used during implementation.

## What Belongs Here

- External references permitted for engineering work.
- Research notes that support implementation decisions.
- Vendor or integration notes after the Integration Context defines the boundary.

## What Does Not Belong Here

- Canonical product or architecture specifications.
- Secrets, credentials, or customer data.
- Application code, generated artifacts, or runtime data.

## Expected Future Directives

- ED-0004 Development Tooling may define reference standards.
- Future integration directives may add approved adapter reference notes.
