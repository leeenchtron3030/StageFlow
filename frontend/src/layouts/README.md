# Layouts

## Purpose

`layouts` is reserved for reusable layout composition.

## What Belongs Here

- Future application shell layouts.
- Workflow layout primitives.
- Responsive layout helpers.

## What Does Not Belong Here

- Operational dashboards before approved.
- Route-level business logic.
- Backend API clients.

## Expected Future Directives

- Future frontend workflow directives may add role-specific layouts.
