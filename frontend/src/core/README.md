# Core

## Purpose

`core` is reserved for frontend application-wide foundations.

## What Belongs Here

- Application providers.
- Cross-cutting frontend configuration.
- Future query client setup.
- Future form or validation wiring shared by workflows.

## What Does Not Belong Here

- Workflow-specific screens.
- Backend API clients before backend communication is approved.
- Authentication logic.
- Entity-oriented feature folders.

## Expected Future Directives

- ED-0004 may add development tooling integration.
- Future frontend directives may add application providers and query client composition.
