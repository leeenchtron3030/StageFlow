# Workflows

## Purpose

`workflows` is the future home for role-oriented StageFlow frontend experiences.

## What Belongs Here

- Technical Director workflow surfaces.
- Content Lead workflow surfaces.
- Reviewer workflow surfaces.
- Package Delivery workflow surfaces.
- Simulation workflow surfaces.

## What Does Not Belong Here

- Database-entity-oriented feature folders.
- Shared generic components.
- Backend API clients.
- Business logic before future directives approve it.

## Expected Future Directives

- Future workflow directives will populate these packages with operational experiences.
