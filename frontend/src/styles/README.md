# Styles

## Purpose

`styles` contains frontend styling foundations that are not tied to a specific workflow.

## What Belongs Here

- Design tokens.
- Styling constants.
- Future theme support utilities.

## What Does Not Belong Here

- Workflow-specific style overrides.
- Visual design systems beyond approved foundations.
- Alternate themes before theme directives approve them.

## Expected Future Directives

- Future design-system directives may expand the token model and theme mappings.
