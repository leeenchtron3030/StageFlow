# assets

## Purpose

This directory is reserved for repository-managed static assets that support documentation, examples, or future product surfaces.

## What Belongs Here

- Approved diagrams, screenshots, and static documentation assets.
- Small design or reference assets needed by future directives.
- Non-runtime assets that are intended to be versioned.

## What Does Not Belong Here

- Runtime media.
- Event recordings, exports, transcripts, thumbnails, or generated captions.
- Large binary artifacts that should live in external storage.
- Frontend application assets before a frontend directive exists.

## Expected Future Directives

- ED-0003 Frontend Foundation may define product asset conventions.
- Future documentation directives may add architecture or workflow diagrams.
